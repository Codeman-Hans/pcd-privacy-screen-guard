# Folder Riwayat Belajar — src/tahap/

Folder ini berisi file-file dari setiap **tahap pengembangan** proyek sebagai jejak proses belajar.
File di sini **tidak perlu dijalankan** untuk demo akhir; gunakan `src/main.py` sebagai program utama.

| File | Deskripsi |
|------|-----------|
| `tahap2_deteksi_wajah.py` | Tahap 2 — Deteksi wajah dasar dengan BlazeFace |
| `tahap3_status.py` | Tahap 3 — Penilaian status (AMAN/WASPADA/BAHAYA/PERGI) |
| `tahap4_blur.py` | Tahap 4 — Penutupan layar dengan Gaussian blur |
| `tahap5_layar_nyata.py` | Tahap 5 — Overlay layar nyata + alarm suara |
| `tahap6_analisis.py` | Tahap 6 — Penilaian arah yaw dan jarak |
| `tahap7_log.py` | Tahap 7 — Log CSV, jeda (tombol P), foto kejadian |
| `tahap8_pemilik.py` | Tahap 8 — Pengenalan pemilik dengan LBPH |
| `tahap9_cahaya.py` | Tahap 9 — CLAHE cahaya redup + slider interaktif |
